# Tests the new `/` breaks

Inventory for #141, recorded in #142 so that #144 can justify each change when it replaces the
hub at `/` with the flat site. It classifies; it changes no test.

The new `/` (ADR-0007, #141 Scope): a header with name, role and the current subhead; the drawn
path with its seven steps and two side props; the piece, the step panel and seen ticks; writing
visible; the footer. Gone: `HubShell`, the sticky rail with its scroll-spy, and the mobile route
bar. Kept as written: `tests/homepage-fold.spec.ts` and the retained-proof check in
`tests/cv-route.spec.ts`.

- **keep** — the test asserts something the new `/` still has, through selectors that survive.
- **update** — the contract stays, but the test reaches it through hub markup (a test id, a
  section, a rail element) that changes. #144 repoints it at the flat site's equivalent.
- **remove** — the test asserts a feature that is retired. Each removal names the decision that
  retires it.

Coverage: `responsive-hub-shell.spec.ts` plus the 17 other spec files that visit `/`, plus
`tests/support/routes.ts` — 19 files. Where a group is marked, every test in it shares the mark. Line numbers are at 8135bfe.
