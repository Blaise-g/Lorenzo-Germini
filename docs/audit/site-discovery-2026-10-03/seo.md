## Primary requirements checked

- [Google ProfilePage](https://developers.google.com/search/docs/appearance/structured-data/profile-page): required Person/name and optional DateTime semantics.
- [Google sitemaps](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): lastmod reflects significant changes; priority/changefreq ignored.
- [Google canonicalization](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls): HTTP canonical mechanism.
- [Google speakable](https://developers.google.com/search/docs/appearance/structured-data/speakable): supported news feature.

No private Search Console URL inspection/indexing, sitemap submission history, rich-results report, field CWV, geography-specific ranking, or full external link crawl available. OG URLs advertised correctly; card raster/font rendering and all image status checks not performed. PDF header/access verified; PDF text/layout not re-reviewed. No check is marked failed because its tool was unavailable.
