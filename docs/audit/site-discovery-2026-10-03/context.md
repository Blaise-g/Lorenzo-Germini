## Site type, language, and ownership

This is a personal professional hub, portfolio and CV, with an off-site publication. It is not an ecommerce store, a local-business directory listing, or the employer's corporate site. Quadrell is a separately linked independent studio project, not a reason to transform this site into a services landing page. Visible identity, professional record, project descriptions and agent engagement guidance belong to Lorenzo; business/copy decisions remain his. The canonical profile source is [RESUME_DATA](../../../src/data/resume-data.tsx).

Current authored site language is English (`html lang=en`, English metadata and schema language). Person JSON-LD states that Lorenzo knows English, Italian and French; this does not mean three localized website versions exist. Bilingual EN/IT remains an optional future surface when Italian publishing actually begins; the signed spec explicitly rejects pre-building language filtering without feed language data ([open inputs](../../spec/redesign-implementation-spec.md#open-inputs-this-spec-does-not-decide), [Phase 3](../../spec/redesign-implementation-spec.md#phase-3--optional-advanced)).

“Field note” is reader-facing terminology; “essay” is the internal feed-item term. “Essay index” denotes `/writing`; the archive is hosted on Substack. A Project is a built thing; a System is something built with. Audit proposals should use the [domain glossary](../../../GLOSSARY.md#content-surfaces), not introduce a blog/archive vocabulary or call projects systems.

## Existing decisions to preserve

- **Technical proof is protected:** the machine-readable [retained-proof manifest](../../spec/retained-proof.json) wins over explanatory prose. Named technical nouns and quantified proof across `/` + `/cv` must survive; the fold also has technical-proof requirements. Generic simplification or marketing rewriting cannot erase them.
- **Identity consistency is deliberate:** shared `#person` and `#website` identifiers, accurate role label separate from employer job titles, and contact/social links derive from [Person builder](../../../src/lib/person-structured-data.ts). Summary, about, role label, metadata, manifests and route descriptions are separate surfaces. Generated markdown narrows this drift risk; it does not make hand-maintained manifests generated ([glossary](../../../GLOSSARY.md#content-surfaces)).
- **Markdown addressability plus negotiation is accepted:** [ADR-0005](../../adr/0005-markdown-siblings-with-an-accept-shim.md), [proxy](../../../src/proxy.ts) and [negotiation](../../../src/lib/markdown-negotiation.ts) map all three content paths to siblings. GET/HEAD only, explicit markdown media type, q-values honored. HTML-preferring traffic stays HTML. No speculative 406 behavior is required.
- **Production cache behavior is load-bearing:** sibling handlers await `connection()` so `Vary: Accept` survives production; rewritten sibling paths also separate CDN cache keys. Local `next dev` cannot prove Vercel headers/cache behavior. ADR-0005 declines trust-anchor pages, employer contact information and brand-name-search scoring on merit. Its partial agent-friendly-404 result is intentional: rejected catch-all/manifest hacks must not be repeated without a new viable mechanism.
- **Publication remains external:** minimal Blog schema is shipped; Article-per-excerpt schema, first-party MDX, Substack custom domain and bilingual structure are conditional Phase 3 choices. More schema is not inherently warranted. The spec flags duplicate/canonical ambiguity when excerpt bodies are off-site.
- **Host authority is explicit:** [site-hosts](../../../src/lib/site-hosts.ts) fixes apex `https://lorenzogermini.com`; retired `lorenzo-germini.vercel.app` permanently preserves paths, while `germinai.xyz` and `www.germinai.xyz` temporarily send every path to `/writing`. A later publication-domain switch remains open. Apex-www handling is also checked by the live verifier, but is not a Next redirect rule in the checkout.
- **Visual/interaction contracts:** [ADR-0001](../../adr/0001-warm-print-has-seven-colour-roles.md) fixes seven Warm Print roles; [ADR-0002](../../adr/0002-each-shell-owns-its-footer-inset.md) keeps main/footer in RouteFrame with route-owned geometry; [ADR-0003](../../adr/0003-chrome-controls-sit-in-flow-instead-of-reserving-gutters.md) removes floating command chrome and reserves BackToTop for available desktop margin; [ADR-0006](../../adr/0006-uppercase-labels-use-space-grotesk.md) consciously adds the fourth font family. Performance recommendations that reverse these choices need measured benefit and explicit conflict accounting.
